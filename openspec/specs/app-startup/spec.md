# app-startup Specification

## Purpose

Описывает сборку и жизненный цикл сервиса: приложение должно импортироваться и запускаться, каждый маршрут регистрируется один раз, схема БД создаётся при старте, а пул соединений закрывается при остановке.

## Requirements

### Requirement: Приложение импортируется и запускается
Приложение SHALL импортироваться без ссылок на отсутствующие модули и SHALL запускаться командой `python -m testlab`. Консольная команда `testlab` SHALL запускать тот же сервер, поскольку указывает на callable, а не на объект приложения.

#### Scenario: Запуск через python -m
- **WHEN** выполняется `python -m testlab`
- **THEN** сервер стартует на `127.0.0.1:8000` и открытая документация содержит все зарегистрированные маршруты

#### Scenario: Запуск консольной командой
- **WHEN** выполняется установленная команда `testlab`
- **THEN** сервер стартует так же, как при `python -m testlab`

### Requirement: Каждый маршрут регистрируется один раз
Сборка приложения SHALL регистрировать каждый маршрут ровно один раз; `GET /auth/me` SHALL существовать в единственном экземпляре.

#### Scenario: Схема маршрутов
- **WHEN** приложение собрано
- **THEN** в `app.routes` нет двух маршрутов с одинаковым методом и путём

### Requirement: Схема создаётся при старте, пул закрывается при остановке
При старте приложение SHALL создавать недостающие таблицы и оставлять движок работоспособным для обработки запросов; пул соединений SHALL закрываться при остановке приложения, а не сразу после создания схемы.

#### Scenario: Первый запрос после старта
- **WHEN** приложение стартовало и получило первый запрос к материалу
- **THEN** запрос обслуживается, соединение с БД открывается, а не падает из-за закрытого пула

#### Scenario: Остановка приложения
- **WHEN** приложение останавливается
- **THEN** пул соединений закрывается без ошибок

### Requirement: Схема пересоздаётся командой
Команда `testlab-init-db` SHALL создавать схему, а `testlab-init-db --reset` — удалять и создавать её заново.

#### Scenario: Пересоздание схемы
- **WHEN** выполняется `testlab-init-db --reset`
- **THEN** все таблицы удалены и созданы заново, команда завершается с кодом 0
