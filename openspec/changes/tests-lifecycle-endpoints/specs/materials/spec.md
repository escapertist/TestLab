# Spec Delta

## MODIFIED Requirements

### Requirement: Повторная генерация теста отклоняется
Если у материала уже есть тест в статусе `draft` или `published`, `POST /materials/{material_id}/tests` SHALL возвращать `409` и не создавать второй тест. Тест в статусе `archived` SHALL считаться историей и не блокировать создание нового теста.

#### Scenario: Повторный вызов действия
- **WHEN** преподаватель повторно вызывает создание теста для материала, у которого есть тест в статусе `draft` или `published`
- **THEN** ответ `409`
- **AND** в карточке остаётся прежний тест, новые вопросы не появляются

#### Scenario: Создание после архивации
- **WHEN** единственный тест материала находится в статусе `archived`
- **THEN** ответ `201` с новым тестом в статусе `draft`
- **AND** архивный тест остаётся в списке тестов со своим статусом

#### Scenario: Создание после удаления
- **WHEN** единственный тест материала был удалён
- **THEN** ответ `201` с новым тестом в статусе `draft`

### Requirement: Карточка материала
`GET /materials/{material_id}` SHALL возвращать `200` с полями материала и вложенным последним тестом (по `created_at`, затем `id`, по убыванию) с вопросами, вариантами и рубриками, либо `test: null`, если тестов у материала нет.

#### Scenario: Карточка своего материала
- **WHEN** преподаватель запрашивает существующий свой материал, по которому создан тест
- **THEN** ответ `200` содержит материал и последний созданный тест с вопросами

#### Scenario: Карточка материала без теста
- **WHEN** преподаватель запрашивает свой материал, по которому тестов нет
- **THEN** ответ `200` содержит `test: null`
- **AND** файл материала при этом скачивается

#### Scenario: Карточка после удаления теста
- **WHEN** единственный тест материала удалён
- **THEN** ответ `200` содержит `test: null`

#### Scenario: Серверный путь к файлу не раскрывается
- **WHEN** клиент получает карточку, список или результат загрузки
- **THEN** ни один ответ не содержит `file_path` и другие серверные пути
